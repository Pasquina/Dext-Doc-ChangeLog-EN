## Welcome to your new Documentation Project

Here are a few tips to get started:

### Create Topics
* Press @icon-duotone-plus-circle **ctrl-n** to create a new Topic
* Enter text into the main text area using [Markdown formatting](https://markdownmonster.west-wind.com/docs/Markdown-Monster-Documentation/An-Introduction-to-Markdown.html)
* Use the Topic pane on the right to enter topic meta data
* Navigate topics @icon-duotone-list-tree in the Project pane on the left
* Use drag and drop in the Topic tree to move topics around

### Editing and Linking
* Use the @icon-duotone-image Image toolbar button to select images from disk 
  or the Web or to paste images from Clipboard
* Paste @icon-duotone-paste **ctrl-v** images into the editor from the Clipboard or   
  Drag and drop from Explorer or @icon-duotone-folder-open Folder Browser and   
  Save images in your project tree
* Use @icon-duotone-up-right-from-square for external links
* Use @icon-duotone-list-tree to link other project topics
* Embed @icon-duotone-code **alt-a** syntax colored Code Blocks 
* Use back ticks for  `` `inline` `` code
* Use @icon-duotone-table to create, edit or format tables interactively

### Output Generation
* Use @icon-duotone-screwdriver-wrench to generate a static Html Web site
* Use @icon-duotone-cloud-upload to publish your project  
  <small>*publish to:* Web Site &bull; Pdf Document &bull; Html Document</small>
